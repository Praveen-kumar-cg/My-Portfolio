# Praveen Kumar — Portfolio

A responsive personal portfolio made with plain HTML, CSS, and JavaScript. It has no build step or package dependencies.

## View the site

Open index.html in a modern browser, or open this folder in Codex. The site is designed to work on phones and desktops.

## Update it

- Edit the profile copy, links, and project details in index.html.
- Replace assets/praveen-kumar.png with a new portrait (keep the same filename, or update the image path in index.html).
- Add projects by copying a project card in index.html and updating its category and links.
- Update the learning list in the Skills section as your toolkit grows.
- Keep descriptions grounded in your actual role and experience.

The Tiffin Box card includes a Figma Community preview and a direct link to the original file. PixelRush links to the Team CyberSpark SU repository.
